# agent-failures

真实 agent 失败案例集：**每条都带时间、环境、复现步骤、期望 vs 实际、根因、修法**。

不是吐槽合集。目的只有一个：让下一个做 agent 的人少踩一次同样的坑，也让"agent 到底会怎么坏"这件事有可复现的证据。

## 为什么值得记

- 行业里顺利的 demo 太多了，真实失败几乎没有公开记录
- 大部分坑不是模型不聪明，是**接口、焦点、状态、速率**这些笨问题
- 每条失败都是免费的评测样本：能复现，就能进回归测试

## 每条案例的格式

```markdown
## 短标题（一句话说结论）

- 日期 / 时长
- 环境：OS、客户端、模型
- 现象
- 复现步骤（编号，可照做）
- 期望 vs 实际
- 根因（找到就写，找不到写"未定位"）
- 修法 / 现在的规避手段
- 教训（一句话）
```

## 收录标准

- 必须是**真实发生**的，不许编
- 必须能**复现**，或者至少能说清为什么不能复现
- 涉及账号、路径、令牌的一律脱敏
- 不确定的写"未定位"，不许猜一个原因充数
